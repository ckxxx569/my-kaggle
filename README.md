# Maze crawler 多智能体策略 AI
基于规则驱动的多智能体竞赛AI，面向 Maze crawler 实时策略游戏开发，实现单位协同、路径规划、应急逃生等核心能力。

## 📖 项目简介
本项目针对 **Maze crawler** 网格策略竞赛开发纯规则式多智能体 AI 智能体，不依赖深度学习，依靠 BFS 路径规划与分层决策逻辑，解决地图滚动吞噬、友军碰撞、资源短缺、墙体阻挡等游戏核心难题。
AI 可稳定控制工厂、工人、侦察兵、矿工四类单位分工协作，保障核心工厂长期存活，持续采集能量水晶，突破迷宫墙体限制，大幅提升对战存活回合与综合胜率。

## 🎮 游戏背景与核心目标
1. **核心规则**：游戏地图持续向南滚动，工厂一旦被卷出地图底部则直接失败。
2. **主要任务**
   - 保护工厂，主动向北推进，规避地图吞噬风险；
   - 控制多类单位采集能量水晶，维持全局能量循环；
   - 工人拆除墙体开辟通路，单位间避免碰撞自毁；
   - 最大化存活回合数，提升竞赛对战表现。

## ✨ 核心功能与技术亮点
### 1. 核心功能
- **分层决策架构**：数据观测 → 环境建模 → 目标选择 → 路径规划 → 动作输出，逻辑清晰易维护；
- **BFS 智能寻路**：带时间限制的广度优先搜索，为单位规划最短、安全通行路径；
- **工厂应急机制**：实时判断工厂与南边界距离，危险状态下优先跳跃逃生；
- **单位分工协作**：侦察兵探索+采集水晶、工人拆墙开路、矿工转化矿点、工厂建造单位+主力推进；
- **防碰撞系统**：位置预留集合 + 单位优先级排序，将友军碰撞率降至 5% 以内；
- **数据容错处理**：坐标校验、边界判断、异常数据过滤，保证动作合法无报错。

### 2. 技术栈
- 编程语言：Python 3.x
- 核心算法：BFS 广度优先搜索、曼哈顿距离计算、贪心策略、状态机决策
- 运行环境：Maze crawler 官方竞赛环境

## 🚀 快速使用
### 1. 环境要求
仅需标准 Python 环境，代码依赖 Python 内置库，**无需额外安装第三方包**。
内置模块：`collections(deque)`、`time`

### 2. 运行方式
1. 克隆/下载本仓库所有文件；
2. 将 `main.py` 部署至 Maze crawler 竞赛运行环境；
3. 直接启动运行，AI 自动完成所有单位决策与动作执行。

### 3. 核心调用入口
整个 AI 的逻辑入口为 `agent(obs, config)` 函数，接收游戏实时观测数据 `obs` 和全局配置 `config`，返回所有单位的执行动作。

## 🧩 核心模块解析
1. **基础工具函数**
   - 坐标解析、曼哈顿距离计算、位置偏移、墙体判断、边界校验；
2. **全局状态管理**
   - 记录地图边界、已知墙体、水晶、矿点、已探索区域，实现状态持续更新；
3. **单位行为逻辑**
   - 工厂：危险逃生、向北推进、按需建造单位；
   - 工人：拆除前方墙体，开辟通行道路；
   - 矿工：前往矿点完成资源转化；
   - 侦察兵：优先采集水晶，探索未知区域；
4. **安全机制**
   - `reserved` 位置预留集合，提前锁定下一回合位置，杜绝友军碰撞。

## 📈 版本迭代与优化历程
1. **基础版**：实现基础单位控制，存在工厂易被吞噬、单位碰撞、能量断裂等问题；
2. **优化版 1**：新增工厂紧急逃生、工人拆墙逻辑，提升工厂存活率；
3. **优化版 2**：接入 BFS 寻路，替代随机移动，大幅提升水晶采集效率；
4. **优化版 3**：增加位置预留与单位优先级，彻底解决友军碰撞问题，实现稳定运行。
